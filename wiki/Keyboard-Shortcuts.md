# Keyboard Shortcuts

## Card composer (when adding a new card to a list)

| Key | Action |
|---|---|
| `Enter` | Add the card and keep the composer open for the next one |
| `Shift` + `Enter` | Insert a newline in the card title |
| `Escape` | Close the composer without adding a card |

## List / card title editing

| Key | Action |
|---|---|
| `Enter` | Save the new name |
| `Escape` | Discard changes and revert |
| Click away | Save the new name |

## Card detail view

| Key | Action |
|---|---|
| `Escape` | Close the card and return to the board |

## Comment composer

| Key | Action |
|---|---|
| `@` | Open the member-mention dropdown; keep typing to filter |

More shortcuts (board-wide search focus, card navigation with arrow keys,
quick-assign-to-me) are planned — see [Roadmap](Roadmap.md). If you'd like to
help build them, see [Contributing](Contributing.md).
